# Contributing

1. Clone the repository (or fork it if you do not have write access).
2. Create a feature branch.
3. Follow README setup with your own credentials and local database.
4. Keep changes focused; preserve saved user data and authentication boundaries.
5. Run TypeScript checks, relevant tests and the build.
6. Open a pull request describing behavior and validation.

Never add API keys or private store data to commits, issues or screenshots. Changes here do not automatically deploy the existing hosted site.
